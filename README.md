# RDP UltraVNC Auto-Deploy

Автоматическое развертывание и запуск UltraVNC для каждого RDP пользователя с индивидуальным портом.

- Скачивание дистрибутива `UltraVNC.zip` из GitHub Releases
- Автоматическое вычисление портов (`user-1` -> 5901, `user-10` -> 5910)
- Расшифровка VNC-ключа на лету без хранения пароля в открытом виде
- Изолированный запуск `winvnc.exe` в контексте активной RDP-сессии
